🌦️ Weather App

A responsive Weather App built using HTML, CSS, and Vanilla JavaScript. This application fetches real-time weather data from a weather API and displays information such as temperature, weather conditions, humidity, wind speed, and location.

The project demonstrates how to work with REST APIs, Fetch API, asynchronous JavaScript, DOM manipulation, and dynamic UI updates. It provides a clean and responsive interface that allows users to quickly search for the current weather in any city.

This project is ideal for developers learning how to integrate external APIs into frontend applications while building practical and interactive web projects.

✨ Features

🌍 Search weather by city

🌡️ Live temperature

☁️ Weather condition

💨 Wind speed

💧 Humidity

📍 City & country information

📱 Responsive design

🛠️ Tech Stack

HTML5

CSS3

JavaScript (ES6)

Weather API
